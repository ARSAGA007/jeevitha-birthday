# Jeevitha Birthday Website
A special interactive birthday surprise website 💗🎂

## Features
- 🎁 Gift box opening animation with confetti
- 📸 10 personal photos in polaroid frames with lightbox
- 💌 5 friendship birthday wishes
- 🎀 3 interactive flip cards
- 🎊 Grand reveal screen with full photo collage + birthday letter
- 🌸 Full pink aesthetic with animations
- 📱 Mobile-first responsive design

## How to Open
Open `index.html` in any browser — no server required.
